## How this index works

Add a new row for every paper. Keep the source PDF in this folder and create a companion summary note named after the paper's topic. Link the summary with a `[[wikilink]]` so it shows up in the graph view and backlinks. Use the `Field` column to group related work; over time, tags and the graph make clusters of related papers easy to spot.
